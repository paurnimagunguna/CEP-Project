# QR Entry Management System - College Events

A professional and feature-rich web application for managing college event registrations using QR codes.

## ✨ Features

### 1. **Event Registration**

- Register for college events with full details
- **Real QR code generation** using QRCode.js library
- Download QR code as PNG image
- Multiple event selection
- Student year classification
- Form validation and data persistence

### 2. **Event Browsing**

- Browse all upcoming and ongoing events
- **Advanced search and filtering** by name and status
- **Event details modal** with comprehensive information
- Quick registration from event cards
- Clickable event cards for detailed view

### 3. **Entry Gate Scanner**

- **Real-time QR code scanning** using Html5Qrcode library
- Camera integration with permission handling
- Automatic validation of scanned QR codes
- Duplicate entry prevention
- Live entry count tracking
- Denied entries counter
- Success rate calculation

### 4. **Admin Panel**

- Secure login with authentication
- Analytics dashboard with key metrics
- Event creation and management
- **Dynamic registration table** with real data
- Data export (CSV, PDF, Print)
- Real-time entry monitoring
- Registration details view

### 5. **User Profile Management**

- User profile settings
- Event history tracking
- Quick access profile menu
- Session management

### 6. **Dark Mode**

- Toggle between light and dark themes
- Persistent theme preference
- Smooth transitions

### 7. **Professional UI/UX**

- Modern gradient header with icons
- Responsive design (Mobile, Tablet, Desktop)
- Smooth animations and transitions
- Color-coded status badges
- Intuitive navigation tabs
- Clean typography and spacing

## 🎨 Design Highlights

- **Color Scheme**: Indigo primary (#6366f1) with green accents for success
- **Typography**: Modern Segoe UI font for clean readability
- **Shadows & Depth**: Professional shadow effects for visual hierarchy
- **Icons**: Font Awesome icons for better visual communication
- **Animations**: Smooth fade-in and slide-in animations
- **Accessibility**: High contrast ratios and clear visual feedback
